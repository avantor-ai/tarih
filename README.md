# Тас жазулар — Бабалар үні

Сайт, который переводит древнетюркские рунические надписи и казахское төте жазу
(арабица Ахмета Байтұрсынұлы) на современный казахский язык.

---

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

Сайт **полностью работает без API-ключа** — включён демо-режим на эталонной базе.

## Подключить AI-режим (Gemini)

1. Скопируйте `.env.example` → `.env`
2. Впишите ключ из https://aistudio.google.com/apikey

```
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-2.5-flash
```

3. Перезапустите `npm run dev`

Тумблер «AI режимі» на странице переводчика станет активным. Пока ключа нет,
он показан серым с пометкой «кілт жоқ» — это нормально.

**Ключ никогда не попадает в браузер.** Фото уходит на локальный прокси
(`server/index.js`), а тот уже обращается к Gemini.

---

## Как работает распознавание

Два независимых пути, переключаются тумблером:

**Демо-режим (по умолчанию)** — работает офлайн.
Фото сравнивается с эталонной базой из 22 памятников по перцептивному хэшу
(dHash + pHash, 256 бит, с поправкой на пропорции кадра). Если совпадение найдено —
показывается готовая академическая транслитерация и перевод.

**AI-режим** — требует ключ и интернет.
Фото уходит в Gemini Vision, модель пытается прочитать даже незнакомую надпись.

**Транслитерация — настоящий алгоритм, а не таблица готовых ответов.**
Работает на любом введённом тексте:

- руника → латиница → казахский, с определением ряда гласных по твёрдым/мягким
  вариантам согласных;
- төте жазу → кириллица, с учётом дәйекші (хамзы) и сингармонизма;
- обратное направление: казахский → руника и казахский → төте жазу
  (виртуальные клавиатуры на странице переводчика).

### Точность (замер 2026-09-10, 22 эталона)

| Условие | Результат |
|---|---|
| Чистая копия изображения | 22/22 |
| Кроп 10%, наклон 3° | 22/22 |
| Кроп 15%, наклон 5°, тусклый свет | 22/22 |
| Кроп 25%, наклон 8°, темно, мелко | ~70% |
| Посторонние изображения | 0 ложных срабатываний |

В несработавших случаях система ставила правильный памятник на первое место,
но не дотягивала до порога и честно отвечала «не найдено» — вместо того чтобы
выдать чужой ответ.

## Структура

```
public/dataset/
  runic/          12 фото древнетюркских памятников
  tote/           10 образцов төте жазу
src/
  data/
    monuments.json        паспорта 22 эталонов: транслитерация, перевод, регион
    alphabet-runic.json   73 знака, Unicode Old Turkic, орхонский/енисейский варианты
    alphabet-tote.json    33 буквы төте жазу
  lib/
    translit.js     движок транслитерации
    imageHash.js    перцептивный хэш и поиск по базе
  three/
    Stela.jsx       процедурная 3D-модель стелы Кюльтегина
    textures.js     генерация текстуры камня и высеченных рун
    HeroScene.jsx   сцена: степь, холмы, пыль, свет, камера
  i18n/kk.js        все тексты сайта
server/index.js     прокси к Gemini
tests/              тесты транслитерации и точности распознавания
```

3D-модель не загружается файлом — стела, камень и руны строятся кодом.

## Тесты

```bash
npx esbuild tests/translit.test.mjs --bundle --platform=node --format=esm --loader:.json=json --outfile=/tmp/t.mjs && node /tmp/t.mjs
```

Тест точности распознавания (`tests/match-calibration.js`) требует браузера —
инструкция внутри файла.

## Добавить свой памятник в базу

1. Положите фото в `public/dataset/runic/` или `public/dataset/tote/`
2. Допишите запись в `src/data/monuments.json`
3. Очистите кэш отпечатков: в консоли браузера
   `localStorage.removeItem('tas-jazular:fingerprints:v1')`

## Мультиязычность

Сейчас интерфейс только казахский. Чтобы добавить русский или английский:
скопируйте `src/i18n/kk.js`, переведите строки, подключите переключатель.
Компоненты трогать не нужно — они читают тексты из объекта `t`.

## Источники

- Изображения: Wikimedia Commons (public domain / CC BY / CC BY-SA) — лицензия
  каждого файла указана в `monuments.json` и в карточке памятника на сайте.
- Алфавит: Unicode Old Turkic (U+10C00–U+10C48), сравнительная таблица
  В. Томсена (1893).
- Транслитерации и переводы памятников: академические издания
  (В. Томсен, С. Е. Малов, Т. Текин).
- Төте жазу: реформа Ахмета Байтұрсынұлы, «Оқу құралы» (1912).

## Ограничения (о них сказано и на самом сайте)

- В древнетюркском письме один знак передаёт два звука (о/ұ, ө/ү, ы/і) —
  часть слов допускает двойное чтение.
- Гласные часто не записывались; их восстановление — научная реконструкция,
  а не результат работы алгоритма.
- Переводы памятников взяты из академических изданий, это не машинный перевод.
